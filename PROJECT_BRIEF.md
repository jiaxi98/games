# Project Brief

## Prompt

Build an original, historically grounded first-person action role-playing game set in medieval Europe, with large-scale battles, at the presentation and action-quality ambition of *DYNASTY WARRIORS: ORIGINS*.

Every visible and interactive area should receive deliberate attention: environment, characters, materials, animation, combat, crowd simulation, AI, physics, audio, narrative, UI, performance, and polish.

Use independent implementation and review agents. Repeatedly build, play, inspect, criticize, profile, fix, and retest. Reviewers must be harsh and must judge the running game rather than source code or a static hero image.

The result must be genuinely interactive and use original content. It must run locally in a browser and be built with Three.js.

## Autonomous product interpretation

The team may choose the exact protagonist, location, conflict, mission, art direction, and mechanics. Favor a tightly composed 5–10 minute vertical slice over an empty open world. The finished experience must demonstrate both personal first-person combat and the sense of participating in a much larger battle.
