# Sandbox Survival

Web-first single-player sandbox survival prototype (Phase 0 baseline).

## Scripts

- `npm run dev`: local Vite server
- `npm run typecheck`: TypeScript checks
- `npm run test:unit`: unit tests
- `npm run test:integration`: integration tests
- `npm run test:e2e`: Firefox Playwright E2E
- `npm run check`: full local quality gate

## Scope of this baseline

- deterministic seed utilities
- initial chunk queue bootstrap
- minimal WebGL scene render with status label
